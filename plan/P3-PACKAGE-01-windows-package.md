# P3-PACKAGE-01：Windows 源码与便携包

状态：`planned`  
负责人：`packaging`  
风险：`R2`  
依赖：`P3-PRIVATE-ACCEPT-01`

## 范围

生成源码安装说明和 PyInstaller 便携包；包含第三方许可证、版本/构建信息、SHA-256、配置
示例、缓存/索引清理、数据库副本边界、升级/降级与回滚说明。包内不得包含私有索引、
缓存、收据、数据库、密钥、联系人或本机路径。

## 验收与回滚

在无开发环境的 Windows 账户上解压启动，完成合成扫描/筛选/Dry Run smoke；逐项验证包
内必需文件与校验和，而非只验证 exe 存在。发布失败时保留已验证源码入口，不分发不完整包。

# Synthetic fixture work plan

## Scope

This directory supplies deterministic, non-private filesystem and SQLite fixtures
for scanner, mapper, decoder, index, filtering and cleanup-planning tests. It
deliberately does not contain a real WeChat database, contact, message body,
encryption key, absolute path, media file, or decrypted output.

## Deliverables

- A standard-library fixture generator that creates a minimal `xwechat_files` tree.
- A documented inventory covering two accounts, media categories, protected
  directories, cache, and a `Rec` forwarded-record layout.
- A symlink/reparse-point probe that is opt-in because Windows developer-mode or
  elevation may not be available.
- A Phase 3 generator covering multi-account records, direct/group sessions,
  date and size boundaries, confidence/status/ownership states, duplicate
  candidates, and protected paths.
- A three-entry SQLite schema matrix with two supported shapes and one explicit
  rejection sample; every row stores only structured metadata and relative paths.
- Acceptance tests that validate public `MediaRecord` payloads and reproducibility.
- A private-baseline template under `tests/fixtures_private.local.example`.

## Acceptance checks

1. `python tests/fixtures_synthetic/build_fixture.py --destination <empty-dir>`
   creates exactly the expected ordinary fixture files.
2. The fixture manifest identifies every protected directory and each safe cache
   sample; no scanner is permitted to infer that protected content is disposable.
3. The `Rec` sample has paired original/thumbnail entries and stable local record
   identifiers, while containing only generated bytes.
4. The optional symlink probe never makes symlink creation a precondition for
   normal fixture generation.
5. `build_phase3_fixture.py` produces byte-identical output for the same seed,
   and the matrix has two supported plus one rejected SQLite schema.
6. The Phase 3 acceptance tests pass with the project runtime and pytest.

## Out of scope

- Actual WeChat decryption, media parsing, and deletion are not exercised here.
- Private local baseline values are kept out of version control.

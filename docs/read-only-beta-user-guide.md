# 微信空间管理器（只读相册版）使用说明

> 一句话：把微信里的照片/文件**平铺成相册**，能看、能筛、能导出、能把不要的移进系统回收站
> （可还原），但**没有任何删除或直接修改微信文件的能力**。
>
> ⚠️ 先读 [免责声明](disclaimer.md)：先备份聊天再动手；清空回收站后无法找回。

---

## 一、它是什么 / 不是什么

| 能做 | 不能做 |
| --- | --- |
| 平铺浏览全部媒体（10 万级，滚动即加载） | 删除微信文件（代码里根本没有这个模块） |
| 按类型 / 大小 / 可用性 / 时间 / 会话筛选 | 直接修改微信目录 |
| 按时间 / 大小 / 名称排序 | 永久删除（回收站可还原） |
| 预览图片（智能 / 缩略图 / 原图） | 联网、上传任何数据 |
| 导出原图到任意文件夹 | 后台静默操作（每个动作都要你确认） |
| 批量导出 / 批量移入回收站 | |

## 三、标准操作流程

### 第 0 步：下载安装（2 分钟）

1. 打开本仓库右侧 **Releases**，下载最新版
   `wechat-space-manager-v*-win64-portable.zip`（约 210MB）。
2. **解压到任意英文路径文件夹**（如 `D:\wechat-space-manager`），不要解压到微信数据目录里。
3. 双击 `wechat-space-manager.exe`。首次运行 Windows SmartScreen 可能提示"未知发布者"：
   点"更多信息" → "仍要运行"（程序开源、无网络行为，可自行检查源码）。
4. 不需要安装 Python、不需要配环境，解压即用。换电脑用时把整个文件夹拷走就行；
   设置（记住的目录/账号）存在本机，不跟着文件夹走。

### 第 1 步：连接（①区）

1. 点 **「自动检测」**。程序按这个顺序找：
   1. **上次成功连接的目录**（记在本机 `settings.json`，所以第二次启动通常已自动填好）
   2. 常规位置（`Documents\xwechat_files` 等）
   3. **各本地磁盘的浅层扫描**（盘根和盘根下一层，能找到 `D:\xwechat_files` 这类自定义位置）

   几个候选都存在时，按"账号数据库字节数"选最大的那个——旧的科学实验残留副本不会盖过真正在用的账号。

2. **没检测到？** 手动填：打开微信 → 设置 → 文件管理，把「文件管理」路径的**上级目录**
   （即包含 `wxid_xxx` 文件夹的那一层）填进「数据目录」。填一次成功后就会被记住，下次不用再填。

3. 「账号」下拉里选账号（**默认已选中最大的**，通常是主账号）。

4. 点 **「连接」**，看状态栏：
   - ✅ `已连接：35 个库 / 1.3 GB；密钥 27 个，未取到 8 个` —— 正常
   - ⚠️ `未取得任何数据库密钥` —— **微信没登录或没运行**，登录后重连
   - 少数库没密钥是正常的，不影响其余库

连接成功后会自动扫描并平铺展示。

### 第 2 步：筛选与排序（②区）

| 控件 | 说明 |
| --- | --- |
| **类型** | 全部 / **原图（可导出）** / 图片 / 缩略图 / 视频 / 文件 / 语音。「原图（可导出）」= 图片族里真正解得开、能导出原图的那些 |
| **最小** | 只看大于多少 MB 的（找占空间的大文件填 `5.0`） |
| **可用性** | 原图可用 / 仅有缩略图 / 源文件缺失 / 不可解码 / 未知 |
| **时间** | `最近 N 天`（新照片）、**`N 天前（更早）`**（清老照片用这个）、`半年以前`、`一年以前`、`自定义日期之前` |
| **会话** | 只看和某个人/某个群的媒体（来自 `msg/attach` 目录归属，图片类可用；下拉里每个会话都标着它在**当前筛选下占多少**，按占用从大到小排；文件/视频按月存放无法归属，会话筛选时会排除并提示） |
| **排序** | 时间（新→旧 / 旧→新）、大小（大→小 / 小→大）、名称（A→Z / Z→A），切换立即重排并回到顶部 |
| **重新加载数据库** | 重新扫盘（换账号或目录变了才需要） |
| **应用筛选** | 只过滤当前已加载的记录（快，不重新扫盘） |

> **清理空间推荐组合**：`类型=全部` + `最小=5.0 MB` + `时间=半年以前` + 排序`大小:大→小`。

### 第 3 步：相册网格（③区左）

- 所有匹配的媒体**平铺**显示，不设数量上限；只解码屏幕附近的部分，滚动到哪加载到哪。
- **Ctrl + 滚轮**调节缩略图大小（和 Windows 文件夹一样），当前看到的那张会保持在原位。
  放大超过已解码的清晰度时，程序会自动用更高分辨率重新解码，不会给你一张糊图。
- 每格下方是 `文件名` 与 `YYYY-MM-DD｜大小`，年份一定显示；视频/文件/语音有角标。
- **单击选中**（右侧显示大图），**Ctrl/Shift 多选**，`Ctrl+A` 全选。
- **双击**：图片/视频在右侧预览；压缩包、文档等直接用系统默认应用打开源文件。
- **右键**：预览、打开、打开所在文件夹、导出、移入回收站，都在这里。
- 文件类格子显示系统图标（文件夹/PDF/Word/压缩包长各自的样），视频格子中央有大播放键。
- 选中单张时，右侧会显示**它来自哪个会话**：`来自「张三」（单聊）` / `来自「家庭群」（群聊）`。
  这是精确归属（目录名就是会话的哈希），不是猜测；文件/视频/语音按月份存放，会如实标注"无法归属"。

### 第 4 步：预览与管理（③区右）

- 选中一张后右侧自动显示大图，也可以点 **「预览图片」** 手动刷新。
- **视频**：选中后自动加载封面，点 **「预览视频」**（或「播放视频」）播放无声抽样预览，
  可暂停；个别加密容器解不开时会写明原因。
- 选中不可预览的文件（或多选）时，右侧旧图会立即清空，不会拿上一张图糊弄你。
- **变体下拉**三档：
  - **智能（小图用原图）** —— 默认。文件 ≤1MB 时直接解原图（实测约 0.2~0.6 秒），
    更大的图仍用缩略图，清晰与速度兼顾
  - **缩略图（最快）** —— 固定用小图
  - **原图（大图较慢）** —— 固定解原图，几十 MB 的大图需要几秒
- 预览成功时状态栏显示的是**源文件大小**（与格子上一致的数字）。
- **导出与"有没有原图"绑定**：只有缩略图、源文件缺失或解不开的记录，「导出原图」
  和「导出后移入回收站」会**直接禁用**，鼠标悬停能看到原因；批量导出则把它们
  计入"跳过 N 项"并逐条写明原因，绝不会假装导出成功。
- **导出原图…** —— 把这张图解密后存到你选的文件夹（导出的是原图字节，不是截图）
- **移到回收站…** —— 把源文件移入**系统回收站**（可还原），逐文件确认 + 写审计收据
- **导出后移入回收站…** —— 先导出、成功后才回收；导出失败的文件**保持不动**
- **批量…** 三个按钮对当前多选生效：一次确认，逐文件执行、逐文件记录结果（失败不中断其余项）

### 第 5 步：缓存管理（④区）

程序在自己的缓存目录 `%LOCALAPPDATA%\WeChatSpaceManager\cache\` 里放解码预览与密钥缓存：

- **「刷新缓存占用」** —— 看现在占了多少
- **「清除解码缓存（预览产物）」** —— 只删预览图，**微信源文件一个都不动**
- **「清除全部本地缓存（含密钥缓存）」** —— 连密钥缓存一起删（下次连接重新提取）

> 方向别搞反：**清除预览不会删原图**；本程序没有"删原图"能力，只有"移入回收站"。

## 四、已知限制

1. **超大文件**：超过 256MB 的源文件不做完整解码（预览可能缺尾部或直接拒绝），属边缘情况。
2. **个别容器仍解不开**：极少数非标准容器会报 `DECODE_FAILED`，会如实给出原因。
3. **视频预览**：选中自动显示封面，可播放无声抽样预览（可暂停）。极少数加密容器
   解不开（封面与抽帧都会如实报错，可右键"打开所在文件夹"自行查看源文件）。
4. **联系人维度**：会话归属已实现（筛选 + 选中照片显示"来自谁"）。**发送/接收方向**
   暂不可判定：图片消息的记录内容在微信 4.x 中是压缩/加密的，文件名也不是消息字段的
   简单哈希（两条关联路径都实测过，证据在 `scripts/probe_message_direction.py` 与
   `scripts/probe_name_join.py`），破解后即可补上方向标注。
5. **回收站操作需要你逐次确认**：没有任何静默删除路径；批量也是一次确认、逐文件执行。

## 五、常见问题

**Q：点「自动检测」没反应？**
A：你的数据目录在很深的位置（浅层扫描只看盘根和下一层）。手动填一次，之后会被记住。

**Q：提示"未取得任何数据库密钥"？**
A：微信没登录或已退出。登录并保持运行，再点「连接」。

**Q：预览一直失败？**
A：按顺序排查：① 微信是否登录（看①区密钥数）；② 变体切到「缩略图（最快）」；
③ 看状态栏错误码。个别容器确实解不开，会写明原因。

**Q：放大后为什么有几秒变糊再变清晰？**
A：放大超过了已解码的分辨率，程序在后台用更高分辨率重新解码，完成后自动替换。

**Q：占多少磁盘？会不会复制我的微信数据？**
A：不复制。缓存只放**解码出的预览图**和**密钥缓存**，有上限并可在④区查看/清除。

**Q：会不会被微信检测、封号？**
A：全程**只读**：不写微信目录、不注入进程、不模拟操作。密钥从本地配置派生 + 读取进程信息，不做内存扫描。

**Q：我的隐私安全吗？**
A：全部在本机完成。不联网、不上传；上次连接的目录/账号记在本机 `settings.json`，不离开你的机器。

## 六、遇到问题怎么报告

请提供（**不要粘贴真实路径、账号、截图内容**）：

1. ①区的「已连接：X 个库 / Y；密钥 A 个，未取到 B 个」
2. 失败时状态栏的错误码（如 `DECODE_FAILED`、`DECODER_UNAVAILABLE`）
3. 操作顺序与当时的筛选/排序设置

**不要**粘贴：wxid、聊天内容、联系人名、完整文件路径、密钥。

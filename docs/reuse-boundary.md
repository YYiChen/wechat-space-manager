# 外部解码器复用边界

第一版不 vendor、复制或打包任何外部解码器的源代码、二进制、资源或测试夹具。解码能力以本项目的公开契约和独立适配层为边界；在未完成选择与审查前，接口只接受本项目自己的 `DecodeRequest` 并返回 `DecodeArtifact`。

若后续决定复用本机已核实的 `wechatauto-replica` 1.2.1，必须满足以下条件：

1. 该复用遵守 Apache-2.0；保留完整许可证、适用的 NOTICE 和版权文本。
2. 不直接把第三方实现散落进扫描、映射、UI 或清理模块；先实现单独的适配层，隔离第三方 API、异常、数据类型和升级影响。
3. 在 `docs/data-and-license-boundaries.md` 补充固定来源/revision、具体使用范围、复制与否、归属文件、维护责任人和回归测试。
4. 在引入前确认不会要求记录或持久化真实聊天数据库、密钥、内存转储或媒体内容。
5. 集成 Agent 完成许可证、隔离、故障路径和真实私有夹具的人工验收后，才能将状态从“候选”改为“采用”。

Apache-2.0 许可条件不构成技术适配、微信版本兼容或公开分发风险的结论；这些问题必须分别验证。

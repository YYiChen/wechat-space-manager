本软件与腾讯公司、微信没有任何关联、合作或背书。它通过读取**你自己电脑上**

## 2. 先备份，再动手

- 强烈建议先用微信自带的**聊天记录迁移/备份**（手机 ↔ 电脑）备份重要聊天，再使用本软件。
- 「移到回收站」是可还原的，但**清空回收站后无法找回**；批量操作前请先拿 2–3 个文件试手。

## 3. 它会对你的微信做什么（以及不做什么）

| 会做 | 不会做 |
|---|---|
| 读取微信数据目录（只读扫描、建索引） | 修改、写入微信目录内的任何文件 |
| 在内存中使用密钥解密数据库副本到**应用自己的缓存** | 上传任何内容到网络（断网也能用） |
| 经你**每次明确确认**后，把选中的媒体文件移入系统回收站 | 永久删除、静默删除、后台自动清理 |
| 把解密后的原图导出到**你指定的文件夹** | 触碰聊天数据库（`db_storage`）、收藏、账号信息 |

等效理解：它的"清理" == 你自己在资源管理器里把某个微信图片/视频文件拖进回收站。
微信对缺失的媒体文件只会显示"无法查看"占位，**不会崩溃、不会丢聊天记录**——
但前提是你只动媒体文件，而本软件的列表里**本来就没有**数据库可选。

## 4. 运行前提与已知风险

- 仅支持 Windows + 微信 4.x；需要微信**登录并保持运行**才能提取密钥。
- 密钥只在内存中使用，不落盘、不记日志、不上传；应用缓存可一键清空。
- 杀毒软件可能对"读取另一进程内存"的行为报警：这是密钥提取的正常原理，
  源码公开可查，介意者请勿使用。
- 部分非标准格式解不开（会如实报错），超大文件（>256MB）不做完整解码。

## 5. 隐私

所有处理都在本机完成。报告 issue 时**不要粘贴**：wxid、联系人名、聊天内容、
完整文件路径、密钥、截图里的照片内容。详见用户手册第六节。

# 私密数据与第三方复用边界

## 数据分类

| 分类 | 例子 | 仓库处理 |
| --- | --- | --- |
| 公开 | 自编源码、合成夹具、文档、开源依赖元数据 | 可提交 |
| 本机私有 | 账号目录、联系人、消息索引、真实媒体、数据库副本、截图 | 必须忽略，不得粘贴进日志或测试 |
| 机密 | 解密密钥、密钥数据库、内存转储、令牌 | 必须忽略；仅瞬时内存使用；不得输出、缓存或遥测 |
| 不可操作保护区 | 微信数据库、收藏、未知归属媒体 | 第一版禁止修改或删除 |

真实“季冬 Rec”材料是本机私有验收夹具：它可用于人工确认映射和解码，但不进入仓库、自动测试、CI、截图或报告。任何聚合结果都不得包含联系人、账号或会话目录标识。

许可证兼容不等于技术适用性或发布许可。实际采用数据库解密、图像格式或 Windows 回收站实现前，必须在本文件增加：SPDX 标识、固定 revision、使用方式、是否复制、NOTICE 义务、测试范围和维护责任人。

具体的第一版“不 vendor”规则和未来适配条件见 [外部解码器复用边界](reuse-boundary.md)。

## 禁止事项

- 不将真实数据库、密钥、内存转储或解码媒体提交到版本控制。
- 不将第三方仓库整体复制进本项目来“复用”；先确认许可证、最小依赖、归属和安全影响。
- 不把私有验收数据发送给 Agent、CI、在线服务或日志收集端。

# 风险模型与强制门禁

风险级别定义见 `AGENTS.md`。风险按照实际副作用而非代码复杂度评定；同一功能可能包含多个等级，取最高等级。

## 默认许可矩阵

| 行为 | 最高默认等级 | 是否可由 Agent 执行 |
| --- | --- | --- |
| 读取合成夹具、生成文档 | R0 | 是 |
| 读取真实目录元数据、建立本地索引 | R1 | 仅用户明确要求且无写入 |
| 在内存中处理密钥、解码到受控缓存 | R2 | 仅用户明确要求；不得外传或留日志 |
| 移入回收站或隔离区 | R3 | 仅未来独立执行器；要求实时人工确认 |
| 永久删除、修改微信数据或数据库 | R4 | 否；必须由独立受限执行器逐次确认 |

## 必须拒绝的条件

- 微信进程运行。
- 清理计划缺少版本、哈希、创建时间、用户确认或逐文件目标。
- 当前文件不再与计划时的路径、大小、修改时间和账号根目录一致。
- 目标是数据库、收藏、未知归属或低置信度映射媒体。
- 清理程序的缓存目录与真实微信目录混淆，或无法证明待删除项来自本程序。

## 审计最小集

未来 `CleanupReceipt` 仅记录计划 ID、操作类型、时间、相对路径的不可逆摘要、删除前验证结果、结果码和恢复位置（如有）。不得记录聊天内容、联系人昵称、账号 ID、密钥或原始绝对路径。
